# Перенос на Mac mini — полная инструкция

От пустого Mac mini до «каждый вечер в 21:00 приходит отчёт мастер → клиенты».
Всё делается в приложении **Терминал** (Программы → Утилиты → Терминал).
Команды копируйте целиком, по одному блоку.

## Что нужно заранее

- Mac mini, подключённый **кабелем** к тому же роутеру, что и регистратор Hikvision.
- Аккаунт GitHub с доступом к репозиторию `stepanboost/fftvv`.
- IP-адрес, логин и пароль регистратора (как в Hik-Connect / iVMS-4200).
- По 3–5 фото **лица анфас** каждого мастера (можно снять телефоном).
- Около 5 ГБ свободного места и 20–30 минут.
- По желанию: Telegram-бот для вечернего отчёта (шаг 9).

## Что переносится и откуда

| Что | Откуда берётся на Mac mini |
|---|---|
| Программа, настройки камер (`config/salon.yaml`), скрипты, автозапуск | `git clone` (шаг 2) — всё уже в репозитории |
| Python, ffmpeg, библиотеки (YOLO, BoxMOT, OpenCV) | ставит `scripts/install_mac.sh` (шаг 3) |
| Модели YOLO, YuNet, SFace | скачивает установщик в `models/` |
| Модель одежды OSNet | BoxMOT скачает сам при первом запуске |
| Пароль регистратора, токен Telegram | вы вписываете в файл `.env` (шаг 4) — в git его нет |
| Фото мастеров | вы кладёте в `masters/` (шаг 6) — в git их нет |
| Данные за день (треки, фото лиц, отчёты) | появляются сами в `data/` |

## 1. Подготовить Mac

1. **Часовой пояс:** Системные настройки → Основные → Дата и время → часовой пояс
   **Астрахань** (UTC+4) — отчёт строится в 21:00 по часам Mac.
2. **Не засыпать и подниматься после отключения света** — в Терминале:
   ```bash
   sudo pmset -a sleep 0 disksleep 0 displaysleep 10 autorestart 1
   ```
   (спросит пароль от Mac — при вводе символы не видны, это нормально)
3. **Автоматический вход:** Системные настройки → Пользователи и группы →
   «Автоматический вход» → ваш пользователь. Без этого после перезагрузки
   программа не запустится. Если опция серая — выключите FileVault
   (Конфиденциальность и безопасность → FileVault).

## 2. Скачать программу

```bash
xcode-select --install 2>/dev/null; true
```
(если появится окно — «Установить», дождаться конца; это git и инструменты)

```bash
cd ~
git clone -b claude/brave-faraday-e4lrpa https://github.com/stepanboost/fftvv.git salon
cd ~/salon
```

Репозиторий закрытый — git спросит логин и пароль GitHub. Вместо пароля нужен
**токен**: github.com → Settings → Developer settings → Personal access tokens →
Tokens (classic) → Generate, галочка `repo`. Его и вставить как пароль.

> Без git: скачать архив
> https://github.com/stepanboost/fftvv/archive/refs/heads/claude/brave-faraday-e4lrpa.zip,
> распаковать, переименовать папку в `salon` и положить в домашнюю папку.
> Тогда обновляться придётся так же, архивом.

## 3. Установить всё

```bash
cd ~/salon
bash scripts/install_mac.sh
```

Скрипт сам ставит Homebrew, Python 3.12, ffmpeg, библиотеки и модели, затем
прогоняет тесты. В конце должно быть `67 passed` и `== Готово`. Занимает
10–20 минут. Запускать повторно можно сколько угодно.

## 4. Вписать пароль регистратора

```bash
open -e ~/salon/.env
```

В открывшемся файле заполнить:
```
NVR_HOST=192.168.1.64        ← IP регистратора
NVR_USER=admin
NVR_PASSWORD=ваш_пароль
```
Сохранить (⌘S) и закрыть.

## 5. Проверить камеры

```bash
cd ~/salon && source .venv/bin/activate && set -a && source .env && set +a
python -m salon_analytics probe --nvr "$NVR_HOST" --out probe
open probe
```

macOS спросит **«Разрешить Терминалу доступ к устройствам в локальной сети?» —
нажать «Разрешить»**. Без этого камеры не откроются (проверить можно в
Системные настройки → Конфиденциальность и безопасность → Локальная сеть).

В папке `probe` — `report.txt` и кадры `cam1.png…cam8.png` с наложенной
разметкой. **Пришлите их мне** — по ним уточню разметку кресел под реальные кадры.

## 6. Зарегистрировать мастеров

Положить фото так (имя папки = имя мастера в отчёте):
```
~/salon/masters/Регина/1.jpg
~/salon/masters/Регина/2.jpg
~/salon/masters/Алексей/1.jpg
...
```
Фото: лицо анфас, светло, без очков и масок, 3–5 штук на человека.

```bash
cd ~/salon && source .venv/bin/activate
python -m salon_analytics register
```
Напротив каждого мастера должно быть «N фото с лицом». Если «НЕТ ЛИЦА» —
заменить фото. Новый мастер пришёл — добавить папку и запустить `register` снова.

## 7. Пробный запуск (5 минут)

```bash
cd ~/salon && bash scripts/run_live.sh
```
Пусть поработает 5 минут, пока по залу кто-нибудь ходит и садится в кресло.
Первый запуск дольше: BoxMOT скачивает модель одежды. Остановить — **Ctrl+C**.

```bash
cd ~/salon && bash scripts/run_nightly.sh
open data/$(date +%Y-%m-%d)/report/masters.html
```
Откроется главный экран «мастер → клиенты» с фото.

## 8. Включить автозапуск

```bash
cd ~/salon && bash scripts/install_mac.sh --autostart
```
Теперь:
- днём запись работает постоянно и перезапускается, если упала;
- каждый день в 21:00 строится отчёт `data/<дата>/report/masters.html`;
- данные старше 90 дней удаляются сами.

Проверка, что работает:
```bash
launchctl list | grep nikolskaya          # две строки: salon-live и salon-nightly
tail -f ~/salon/logs/live.err             # ход работы, выход — Ctrl+C
ls ~/salon/data/$(date +%Y-%m-%d)         # ticks.jsonl, faces.jsonl, faces/ растут
```

## 9. Отчёт в Telegram (по желанию)

1. В Telegram написать **@BotFather** → `/newbot` → получить токен вида `123456:ABC...`.
2. Написать своему боту любое сообщение, затем открыть в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найти `"chat":{"id":...}`.
   Для группы — добавить бота в группу и написать в ней.
3. Вписать в `~/salon/.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   TELEGRAM_CHAT_ID=-100123456789
   ```
Со следующего вечера в 21:00 придут сводка и файл `masters.html`.
Проверить сразу: `cd ~/salon && bash scripts/run_nightly.sh`.

## 10. Обновление программы

Когда я внесу изменения:
```bash
cd ~/salon && git pull && bash scripts/install_mac.sh
launchctl kickstart -k gui/$(id -u)/ru.nikolskaya.salon-live
```
Файлы `.env`, `masters/`, `data/` при обновлении не трогаются.

## 11. Перенос на другой Mac / резервная копия

Всё ценное — в четырёх местах:
```
~/salon/.env                 пароли
~/salon/masters/             фото мастеров
~/salon/data/masters.json    эталоны лиц мастеров
~/salon/data/                история (по дням) и база salon.db
```
Копия на флешку:
```bash
cd ~ && tar czf /Volumes/ФЛЕШКА/salon-backup.tgz salon/.env salon/masters salon/data salon/config
```
На новом Mac: шаги 1–3, затем распаковать копию поверх: `cd ~ && tar xzf /Volumes/ФЛЕШКА/salon-backup.tgz`,
затем шаг 8.

## 12. Выключить / удалить

```bash
launchctl unload ~/Library/LaunchAgents/ru.nikolskaya.salon-live.plist
launchctl unload ~/Library/LaunchAgents/ru.nikolskaya.salon-nightly.plist
```
Включить обратно — шаг 8.

## Если что-то не так

| Признак | Что делать |
|---|---|
| `401 Unauthorized` в probe или `live.err` | неверный пароль в `.env`; после 5 ошибок регистратор блокирует вход на 30 мин |
| `Connection refused` / таймаут | не тот IP, Mac в другой сети, или RTSP выключен в регистраторе (Сеть → Дополнительно → порт 554) |
| Камеры не открываются, хотя пароль верный | разрешить «Локальная сеть» для Терминала (шаг 5) |
| `filterpy` / `boxmot` не ставится | `source .venv/bin/activate && pip install --no-build-isolation filterpy && pip install boxmot` |
| Модель OSNet не скачивается | Google Drive недоступен из сети салона — скачать `osnet_x0_25_msmt17.pt` вручную и положить в `~/salon/models/` |
| В отчёте мастер стал «сотрудник?» | мастер не опознан по лицу — добавить его фото в `masters/<Имя>/` и `register` |
| Отчёт пустой | `tail -50 ~/salon/logs/live.err`; есть ли файлы в `data/<сегодня>/` |
| После перезагрузки не работает | автоматический вход (шаг 1.3) |

## Честно о текущем состоянии

- Распознавание подключено: люди и скелеты — YOLO11-pose, ID — BoT-SORT +
  OSNet (BoxMOT), лица — YuNet + SFace. Цепочка проверена на тестовых
  записях, **на ваших камерах ещё не проверялась** — первые дни сверяйте отчёт
  с журналом записи.
- Пока cam5 смотрит на улицу, вход берётся с cam3 сверху — фото лиц клиентов
  будет мало. Камера на уровне лица у входа — по-прежнему пункт №1.
- Калибровка на план в метрах (`homography_points` в `config/salon.yaml`) не
  заполнена — правило «мастер рядом» работает в долях кадра. Заполним по кадрам из шага 5.
